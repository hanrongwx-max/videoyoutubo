# 05_How to Use a Centrifuge 审查报告

- 原片：How to Use a Centrifuge（实验技巧短片，3 分 16 秒）；内容文档：`course/General Lab Safety Practices/05_How to Use a Centrifuge.md`
- 新剧本：《离心机的正确使用》，70 镜，5 分 50 秒；原片知识点 K1–K9 全部覆盖，审查补充 S1–S7
- 总体结论：原片是离心机操作技巧片，四要点（选对管、配平、拧紧转子盖、查设置）方向正确、与安全直接相关，但只讲了“启动前”，缺少准入登记、个人防护、运行中观察、停稳开盖、取出检查和异常报告；“时间不重要”“液面一致即可”“会爆炸”等说法需要修正或补充。本剧集第 04 集讲离心机维护、第 06 集讲离心危害与生物安全（气溶胶），本剧本对这两部分只点到为止，重点放在正确操作流程。

## 1. 法律法规与国内高校安全教育要求

|---|---|---|---|

## 2. 内容完整性
对照国内高校离心机使用培训的常规内容，补充以下 S 知识点：

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 准入培训与使用登记 | 公用离心机，尤其高速离心机，国内高校普遍要求培训后使用并登记；原片未提 | 40–41 |
| S2 | 个人防护与样品管检查 | 原片徒手操作；未提检查管子裂纹、不超过最大装量、盖紧管盖，这些是防止破管漏液的基本步骤 | 42–45 |
| S3 | 运行前检查转子和腔体 | 腔体有液体、转子未装到位或有裂纹腐蚀，是失衡和转子故障的常见原因；原片未讲 | 46–49 |
| S4 | 更多配平情形 | 原片只演示两支同种溶液的小管；多管对称、用天平按质量配平、吊篮和适配器成对、配平液与样品同介质是常见要求 | 50–53 |
| S5 | 启动与运行中观察 | 原片到“设置”就结束；启动后应等升到设定转速再离开，异响震动立即停机，运行时不倚靠、不在机盖上放物品 | 54–57 |
| S6 | 停稳再开盖，取出样品 | 等转子完全停止、不手刹转子、不强行开盖、取出时检查漏液，原片完全缺失 | 58–62 |
| S7 | 用后整理与异常报告 | 原片面板贴纸写了“用完开盖晾干”但讲解未提；破管和故障应停用并报告负责人。清洁维护细节属第 04 集 | 63–65 |

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| 讲解者徒手拿管、放管、拧转子盖，无护目镜 | 剧本操作镜头角色穿实验服、戴手套（镜 13、30、42）；S2 专门讲防护 |
| “小体积不必称重，液面一致即可”——只适用于同种溶液、同型号小管 | K5 旁白限定为“同种溶液的小管，看体积一致即可”（镜 23）；S4 补充大体积或溶液轻重不同时用天平称量、配平液与样品同介质（镜 51、53） |
| 只有一个样品时“装等体积的水”配平 | 保留原片做法（镜 27），并在 S4 提示配平液尽量与样品溶液一致（镜 53） |
| “时间不太重要，最重要的是转速” | 改为“时间和转速都按实验方案来设”（镜 34），转速不得超过管子和转子的允许上限（镜 35–36） |
| “离心机可能爆炸，真的发生过”（玩笑式） | 改为说明失衡后果：剧烈震动、破管、损坏转子甚至伤人（镜 38–39），并补充异常停机和报告（镜 56、65）；不展示事故细节 |
| 落地高速离心机镜头中讲解者双手在机盖上快速抹动 | 剧本不再现，改为“不是洗衣机，不能随便摆弄”的图标镜头（镜 11）；S5 补“运行时不倚靠、不在机盖上放东西”（镜 57） |
| 仪器品牌、型号、转子型号与额定数值清晰可见 | 剧本画面面板和转子一律空白，不出现品牌型号和转速、载荷数值；只保留通用的 0.5 mL / 1.5 mL 管规格 |
| 错误做法（单管离心、管子相邻放置、小管不套适配器、转子盖松动、手刹转子等） | 一律用图标并打红叉表示（镜 4、18、25、32、57、59） |
