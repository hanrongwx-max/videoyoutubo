# 08_CO2 or Class D Fire Extinguishers with Laser Systems Which should you use Innova 审查报告

- 原片：车间负责人比较激光设备旁的二氧化碳灭火器与 D 类灭火器（77 秒）；内容文档：`course/Laser Maintenance Group Safety/08_CO2 or Class D Fire Extinguishers with Laser Systems Which should you use Innova.md`
- 新剧本：《激光设备旁，选对灭火器》，40 镜，3 分 20 秒；原片知识点 K1–K8 全部覆盖，审查补充 S1–S5
- 总体结论：**原片结论基本正确**（精密带电设备优先用二氧化碳，可燃金属用金属火灾专用灭火器），但按美国分类讲解，只从设备维修费用角度比较，有夸大之处（“干粉融化一切”“金属火扑不灭”），且完全没讲人员风险（二氧化碳窒息、冻伤）、先断电和灭火器检查。剧本本土化为国内六类火灾分类，补充使用方法和人员防护。初起火处置与报警撤离的完整流程见本剧集 02，本片只在 S4 简述。

## 1. 法律法规与国内高校安全教育要求

| 原片内容 | 国内依据 | 结论 | 剧本处理与镜号 |
|---|---|---|---|
| “Class D”“electrical fire”按美国分类 | GB/T 4968《火灾分类》：A 固体、B 液体、C 气体、D 金属、E 带电、F 烹饪油脂（以现行文本为准） | 需本土化 | 补 S1：国内六类火灾，激光车间常见 D 类和 E 类，看清灭火器标签（镜 21–23）；剧本不说“Class D”，改称“金属火灾灭火器” |
| 带电精密设备用二氧化碳，不用干粉 | GB 50140《建筑灭火器配置设计规范》关于各类火灾适用灭火器的规定（以现行文本为准）；本校灭火器配置 | 符合（需说明依据） | 保留（镜 10–18）；“干粉融化一切”夸张说法不采用，改为“残留吸潮、腐蚀金属，清理困难”（镜 12–13） |
| 二氧化碳“排开氧气灭火、挥发不留痕” | 同上；二氧化碳在密闭空间可致人窒息 | 需修改 | 保留原理（镜 14–15）；补 S3 中的窒息风险和灭火后通风（镜 29–30） |
| 未讲灭火器使用方法 | 消防安全常识；学校消防培训（以本校规定为准） | 需修改 | 补 S3：提起、拔销、握手柄、对准火焰根部，喇叭筒冻伤防护（镜 26–28）；只讲通用步骤，不写距离和时间数值 |
| D 类用于钛等可燃金属，“一旦燃烧扑不灭” | GB/T 4968（D 类金属火灾）；GB 50140（以现行文本为准） | 需修改 | 保留 D 类用途（镜 19–20），“扑不灭”改为“很难扑灭，要用专门的灭火器”；补 S4：金属火不用水和二氧化碳，用专用灭火器或干沙，没把握撤离并拨打 119（镜 31–34） |
| 未讲先断电 | 电气火灾扑救常识；《高等学校实验室安全规范》（教科信厅函〔2023〕5 号）关于应急处置的要求 | 需修改 | 补 S2：先按急停、断总电源（镜 24–25） |
| 未讲灭火器检查 | 《中华人民共和国消防法》关于单位消防设施、器材定期检验维修的规定；GB 13495.1 消防安全标志 | 需修改 | 补 S5：查压力和有效期、放在明处不遮挡、检查签卡、用过即换（镜 35–37） |
| “多花一千美元修理费” | 美元金额 | 不采用 | 改为“维修费涨一大截”（镜 11） |
