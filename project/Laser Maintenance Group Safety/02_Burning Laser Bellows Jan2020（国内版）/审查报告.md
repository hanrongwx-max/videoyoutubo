# 02_Burning Laser Bellows Jan2020 审查报告

- 原片：激光切割机光路风琴管被烧穿、阴燃的现场竖拍短片（20 秒，无讲解、无字幕）；内容文档：`course/Laser Maintenance Group Safety/02_Burning Laser Bellows Jan2020.md`
- 新剧本：《风琴管着火了怎么办》，42 镜，3 分 30 秒；原片画面知识点 K1–K5 全部覆盖，审查补充 S1–S7
- 总体结论：**原片只是故障现场记录**，展示了真实的设备火灾隐患（风琴管阴燃、积灰、紧邻气管电缆），但没有讲原因、预防和处置，拍摄者甚至在火未灭时持续拍摄。剧本把它改编为“设备内初起火灾”的完整处置课：发现 → 停激光 → 初起火扑救 → 报警撤离 → 断电检修 → 报告。灭火器类型的详细比较留给本剧集 08（CO2 与 D 类灭火器），本片只讲“用就近合适的灭火器、带电设备不用水”。

## 1. 法律法规与国内高校安全教育要求

| 原片内容 | 国内依据 | 结论 | 剧本处理与镜号 |
|---|---|---|---|
| 风琴管在阴燃，未见任何处置 | 《中华人民共和国消防法》关于发现火灾立即报警、任何人都应当无偿为报警提供便利的规定；教育部《高等学校实验室安全规范》（教科信厅函〔2023〕5 号）关于应急处置的要求 | 需修改 | 补 S2 先停激光（镜 22–24）、S3 初起火扑救（镜 25–27）、S4 火势扩大报警 119、撤离、报告（镜 28–31） |
| 拍摄者在火未灭时持续拍摄 | 同上；先处置、后记录是一般应急原则 | 需修改 | 拍视频图标打叉，“先处置，不要先拍视频”（镜 24） |
| 未说明起火原因和预防 | GB/T 7247.1-2024（以现行文本为准）《激光产品的安全 第 1 部分》关于光束防护的要求；设备说明书和维护规程 | 需修改 | 补 S1：光路偏移、护套塌进光路、镜片脏污和积灰（镜 18–21），具体原因由维修人员诊断；补 S7 日常检查和清灰（镜 37–38） |
| 激光切割机运行时现场是否有人看管不明 | 高校激光切割机等设备安全操作规程普遍要求运行时不得离人（以本校规定为准） | 需本土化 | 补 S5：切割时不得无人看管（镜 32–33）；情景中阿杰看手机作为反面示范（镜 3） |
| 故障后的维修 | 《中华人民共和国安全生产法》；电气作业须持证上岗；检修时断电、上锁挂牌（以本校设备管理规定为准） | 需本土化 | 补 S6：断电上锁挂牌、授权人员更换风琴管和校准光路，学生不得自行拆修（镜 34–36） |
| 未提报告 | 《高等学校实验室安全规范》关于事故报告的要求；三级管理（实验室—学院—学校） | 需修改 | S4 报告老师、学院和保卫处（镜 31）；S7 小火也要如实报告、记录原因（镜 39） |
| 带电设备火灾的灭火器选择 | GB 50140《建筑灭火器配置设计规范》中关于火灾种类和灭火器适用性的规定（以现行文本为准）；国内火灾分类见 GB/T 4968-2008（以现行文本为准）《火灾分类》 | 需本土化 | 只讲“就近合适的灭火器、带电不用水”（镜 25–26），不按美国 A/B/C/D 分类展开；详细选择见本剧集 08 |

## 2. 内容完整性

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 风琴管为什么会着火 | 原片只拍现象，不讲原因，观众无从预防 | 18–21 |
| S2 | 发现冒烟，先停激光 | 切断能量来源是处置第一步，原片未体现 | 22–24 |
| S3 | 初起小火，用对灭火器 | 设备内初起火是最常见的激光切割火灾形态 | 25–27 |
| S4 | 火势扩大：报警、撤离 | 国内要求拨打 119、按下报警按钮、报告保卫处 | 28–31 |
| S5 | 切割时不能无人看管 | 及时发现是阻止阴燃变明火的关键 | 32–33 |
| S6 | 断电上锁，授权维修 | 更换风琴管、校准光路涉及开机内部和激光，须授权人员操作 | 34–36 |
| S7 | 日常检查，事后报告 | 原片隐含的“例行维护”主题需要明确为制度；未遂和小火也要报告 | 37–39 |

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| 火未灭时近距离持续拍摄，未见停机 | 作为反面示范打叉（镜 24），剧本中先急停再处置 |
| 真实的设备燃烧画面 | 改为卡通示意（护套小洞的红光和细烟），不复现真实画面；不渲染火灾后果 |
| 机器内部积灰严重 | 作为隐患讲解（K4），并补清灰（镜 38） |
| 维修细节（光路校准方法） | 不展示校准步骤和参数，只说“交给授权维修人员” |
