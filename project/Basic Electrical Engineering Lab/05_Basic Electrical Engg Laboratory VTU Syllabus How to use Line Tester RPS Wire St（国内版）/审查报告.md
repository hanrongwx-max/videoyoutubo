# 05_Basic Electrical Engg Laboratory VTU Syllabus How to use Line Tester RPS Wire St 审查报告

- 原片：Basic Electrical Engg Laboratory VTU Syllabus How to use Line Tester|RPS|Wire Stripper|Screw Driver（电工工具与直流稳压电源，9 分 16 秒）；内容文档：`course/Basic Electrical Engineering Lab/05_Basic Electrical Engg Laboratory VTU Syllabus How to use Line Tester RPS Wire St.md`
- 新剧本：《电工工具与直流稳压电源》，64 镜，5 分 20 秒；原片知识点 K1–K19 全部覆盖，审查补充 S1–S6
- 总体结论：**原片是工具与设备认识讲座，安全相关度中等**。试电笔的结构和原理讲得较细，但“人体有对地电容所以永远不会触电”的说法过于绝对，没有讲先验笔、不亮不等于没电；稳压电源“限流旋钮始终放最大”与限流保护的用意相反，需要纠正；幻灯片摘录了与电工无关的“压接弹头”条目。剧本保留全部工具知识，改正上述问题，补充试电笔使用、绝缘工具、断电剥线剪线与护眼、稳压电源限流与防短路，以及断电接线、教师检查后通电、触电和电气火灾应急。

## 1. 法律法规与国内高校安全教育要求

| 原片内容 | 国内依据 | 结论 | 剧本处理与镜号 |
|---|---|---|---|
| 试电笔原理：大电阻分压、人体电容，“never get any shock” | GB/T 13869《用电安全导则》；验电前应先在有电设备上确认验电器完好，是国内电气作业通行做法（以现行标准和本校规程为准）；试电笔仅限规定电压范围使用（以产品说明为准） | 需修改 | K4、K5 保留原理（镜 11–14），删去“永远不会触电”；补 S1：先验笔、不亮不一定没电、不碰笔尖、不当螺丝刀用力拧（镜 37–40） |
| 螺丝刀、钳子手柄有绝缘 | GB/T 13869；高校实验室安全检查中对电工工具的检查要求（以本校规定为准） | 需修改 | 补 S2：查绝缘手柄，破损不用，绝缘工具不能代替断电（镜 41–43） |
| 剥线、剪线工具介绍，未讲操作安全 | 《高等学校实验室安全规范》（教科信厅函〔2023〕5 号）关于个人防护的要求；电工实验室断电操作规定（以本校规定为准） | 需修改 | 补 S3：先断电，戴护目镜、线头朝下，线头收好（镜 44–46） |
| 稳压电源“限流旋钮始终放最大” | 仪器说明书；限流用于短路和误接保护；GB 4793 系列（实验室用电气设备安全要求，以现行文本为准） | 需修改 | K16 只讲限流旋钮的作用（镜 33），不保留“始终最大”；补 S4：按实验要求设限流、空载调压后断电接负载、输出不短路、极性不接反（镜 47–50） |
| 未讲断电接线与通电前检查 | 《高等学校实验室安全规范》；高校电工实验室“断电接线、教师检查后通电”的通行规定（以本校规定为准）；电气线路检修由持特种作业操作证的电工进行 | 需修改 | 补 S5（镜 51–54） |
| 未讲触电和电气火灾应急 | 触电急救先断电、不徒手拉人，急救 120；电气火灾先断电、不用水扑救，火警 119；报告实验室负责人→学院→保卫处（以本校应急预案为准） | 需修改 | 补 S6（镜 55–59） |
| 稳压电源输出 0–30 V、2 A 等 | 产品规格 | 需本土化 | 剧本不写数值，改为“看铭牌的输出范围”（镜 34） |

## 2. 内容完整性

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 试电笔要会用 | 原片把试电笔说成绝对安全，未讲验笔和误判风险；“不亮就当没电”是常见触电原因 | 37–40 |
| S2 | 绝缘工具先检查 | 原片提到绝缘手柄，但未讲检查和局限 | 41–43 |
| S3 | 断电剥线剪线，护好眼睛 | 剪线线头弹飞伤眼、带电剪线短路，原片未讲 | 44–46 |
| S4 | 稳压电源：限流设好，输出别短路 | 纠正“限流始终最大”；短路和极性接反会损坏电源和元件 | 47–50 |
| S5 | 断电接线，教师检查后通电 | 用户要求；国内高校电工实验室基本规定 | 51–54 |
| S6 | 触电和起火，先断电 | 原片未讲；国内应急与报告程序 | 55–59 |

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| “人体对地电容，所以永远不会触电” | 删去绝对化表述，改为补充正确使用方法（S1） |
| “限流旋钮应始终放最大” | 剧本不采用，改为按实验要求设定（S4） |
| 幻灯片摘录“压接常用于把弹头接到弹壳上” | 与电工无关，剧本不用，只讲电气端子压接（镜 24–25） |
