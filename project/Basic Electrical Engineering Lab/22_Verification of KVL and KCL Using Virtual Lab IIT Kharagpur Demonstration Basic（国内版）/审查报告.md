# 22_Verification of KVL and KCL Using Virtual Lab IIT Kharagpur Demonstration Basic 审查报告

- 原片：Verification of KVL and KCL Using Virtual Lab（用在线虚拟仿真平台验证基尔霍夫定律的操作演示，16 分 03 秒）；内容文档：`course/Basic Electrical Engineering Lab/22_Verification of KVL and KCL Using Virtual Lab IIT Kharagpur Demonstration Basic.md`
- 新剧本：《在线仿真验证基尔霍夫定律》，64 镜，5 分 20 秒；原片知识点 K1–K17 全部覆盖，审查补充 S1–S4
- 总体结论：**原片不是安全专题片**，是在线仿真实验的电脑录屏演示，没有真实用电。保留全部操作要点（搜索、栏目、连线、检查、选电阻、调压、记录、绘图、打印、复位、结论），平台名称、所属高校、搜索引擎不进入剧本。审查补充：仿真不能代替真实实验的安全培训（仿真接错能重来、真电路不行），先仿真预演再实操；另补本系列 01–21 尚未使用的实验室用电管理要点：突然停电先断开实验台开关、配电箱前不堆物。
