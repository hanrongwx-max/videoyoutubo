# 08_Star Delta Connection Verification of Line and Phase Quantities Basic Electrical 审查报告

- 原片：Star Delta Connection Verification of Line and Phase Quantities Basic Electrical Engineering Lab|VTU（三相星形、三角形线量与相量验证实验，15 分 23 秒）；内容文档：`course/Basic Electrical Engineering Lab/08_Star Delta Connection Verification of Line and Phase Quantities Basic Electrical.md`
- 新剧本：《三相星形与三角形连接实验》，72 镜，6 分 0 秒；原片知识点 K1–K24 全部覆盖，审查补充 S1–S6
- 总体结论：**原片是三相强电实验演示，安全相关度中**。原片做得好的地方：提醒三相实验要做足安全措施、按图接线、检查接头；演示“开关断开、调压器归零接线 → 合闸 → 慢慢升压 → 读数 → 回零 → 断闸”的顺序。主要缺口：没讲三相电的危险性；三角形只升到约 230 V 却不解释原因（每相负载直接承受线电压，不降压会损坏灯泡）；星形改三角形之间没有交代断电、回零、验电；使用 R、Y、B 印度相标；没讲监护；没有应急。本集 S 点按协调要求与本剧集 01–07 不重复。

| 原片内容 | 国内依据 | 结论 | 剧本处理与镜号 |
