## 2. 完整性检查

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| 列出多种抗疟药名、预防用药和止痛药建议 | 不出现药名，统一“遵医嘱、不自行用药” |
| 疟疾“尚无获批疫苗”（已过时）；登革疫苗说法含糊 | 改为“疫苗不断进展，以现行信息为准” |
| 口述“四分之一登革感染者发展为重症”（错误） | 不用；按幻灯片“约四分之一有症状”，重症讲危险信号 |
| 讲疟疾时配伊蚊照片；“北美疟疾回潮”“白蛉 3–5 毫米”等不准确 | 内容文档注明；剧本不用这些说法，画面按正确媒介区分 |
| 疟原虫生活史细节、病毒结构、分子检测原理 | 只保留“人—蚊轮转”“核酸检测更准”的概念，不讲实验方法 |
| 诱捕器构造图、灭幼剂诱捕器、二氧化碳引诱方法 | 不给构造和配方，改为由主管部门统一布点 |
| 转基因蚊子、沃尔巴克氏体释放 | 只作背景，强调须审批、个人不得尝试 |
| 外国地名、公共卫生运动标志、药企与公司名、外国监管机构名 | 不进剧本，已列入 `META["avoid"]` |
| 新冠来源的推测性说法（蝙蝠病毒“刺突蛋白改变”） | 不复述，只讲“很多新病从动物传到人” |
