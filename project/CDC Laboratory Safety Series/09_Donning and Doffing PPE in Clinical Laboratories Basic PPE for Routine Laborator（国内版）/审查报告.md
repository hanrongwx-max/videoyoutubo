# 09_Donning and Doffing PPE in Clinical Laboratories Basic PPE for Routine Laborator 审查报告

- 原片：Donning and Doffing PPE in Clinical Laboratories: Basic PPE for Routine Laboratory Procedures（基本个人防护装备穿脱演示动画，5 分 08 秒）；内容文档：`course/CDC Laboratory Safety Series/09_Donning and Doffing PPE in Clinical Laboratories Basic PPE for Routine Laborator.md`
- 新剧本：《基本防护装备的穿与脱》，79 镜，6 分 35 秒；原片知识点 K1–K19 全部覆盖，审查补充 S1–S5
- 总体结论：**原片是专门的个人防护演示片，相关度高**，穿戴准备、穿戴顺序、“由最污染到最不污染”的脱卸顺序和最后洗手讲得清楚。作为国内高校教材，主要问题是：摘第二只手套的动作有歧义、手卫生只讲结尾一次、防护用品的使用边界和实验服清洗未讲、缺少暴露后处置；数值（洗手 20 秒、手消毒剂浓度）和消毒产品认可体系为美国做法，需本土化。本剧集 10、11 两片讲隔离衣、口罩、面屏，本片补充点只选与基本防护相关的内容，不与之重复。

## 1. 法律法规与国内高校安全教育要求

| 原片内容 | 国内依据 | 结论 | 剧本处理与镜号 |
|---|---|---|---|
| 实验服、手套、侧护安全眼镜为常规操作的基本防护；片尾称按风险评估确定防护 | 《病原微生物实验室生物安全管理条例》；GB 19489-2008（以现行文本为准）《实验室 生物安全通用要求》、WS 233-2017《病原微生物实验室生物安全通用准则》关于个体防护装备和风险评估的要求（具体条款以现行文本为准）；教育部《高等学校实验室安全规范》（教科信厅函〔2023〕5 号）关于个人防护的要求 | 符合 | 完整保留（镜 7–8、53–54）；不写具体实验室级别与防护的对应，按风险评估和本单位规定 |
| 个人物品放实验室外、束发、检查防护用品破损 | 高校实验室安全检查项目表中关于个人防护和实验室行为规范的要求（以本校规定为准） | 符合 | 保留（镜 9–15） |
| 摘第二只手套：“裸手握住翻面手套，再捏另一只手套腕部” | 国内医学和实验室培训中通用的脱手套方法：脱下的手套握在仍戴手套的手中，裸手手指从腕部内侧伸入翻脱，裸手不触及手套外表面（以本单位生物安全手册为准） | 需修改 | 改为通用做法（镜 26–28），并以打叉图标强调裸手不碰手套外面（镜 29） |
| 手套丢入“生物危害废物容器”，污染实验服卷起丢弃 | 《医疗废物管理条例》及感染性废物分类收集要求；实验室感染性废物使用专用包装袋和容器（以本校规定为准） | 需本土化 | 剧本称“感染性废物容器”，画面用生物危害警示标志（镜 30、41） |
| 眼镜用“美国环保部门认可”的产品消毒 | 《消毒管理办法》及消毒产品卫生安全管理要求；本单位规程指定的消毒剂 | 需本土化 | 改为“用规定的消毒剂，作用时间要够”，图示“按说明书”（镜 46），不提国外机构 |
| 洗手“至少 20 秒”；手消毒剂“乙醇不低于 60% 或异丙醇 70%” | WS/T 313《医务人员手卫生规范》（揉搓步骤和时间以现行文本为准）；本单位规定 | 需本土化 | 旁白改为“认真揉搓，时间要够”，图示“按规范揉搓”（镜 49）；不写国外浓度数值，称“速干手消毒剂”（镜 50） |
| 只在脱卸最后洗手 | 同上（手卫生时机） | 需修改 | 补 S2：摘手套后、接触污染后、离开实验室前洗手；六步揉搓；纸巾关水龙头（镜 61–64） |
| 包头、鞋面不透水的鞋 | 《高等学校实验室安全规范》及本校实验室着装要求 | 符合 | 保留，凉鞋拖鞋打叉（镜 52） |
| 穿戴区与脱卸区物理分隔；遵守本单位制度 | GB 19489-2008（以现行文本为准） 关于实验室分区和防护装备存放的要求（以现行文本为准）；三级管理与本单位生物安全手册 | 符合 | 保留（镜 55–57） |
| 未讲暴露后处置 | 《病原微生物实验室生物安全管理条例》关于实验室感染和意外事故报告的规定；本单位应急预案；急救 120 | 需修改 | 补 S5：流水冲洗、洗眼器、报告实验室负责人、就医评估、紧急拨打 120（镜 71–74） |

## 2. 内容完整性

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 防护用品不出实验室 | 原片未讲防护服装的使用边界；穿实验服、戴手套进入办公区或接触门把手、电话、键盘是高校实验室常见违规，会把污染带出实验室；同时强调实验室内不饮食 | 58–60 |
| S2 | 手卫生的时机与步骤 | 原片只讲最后一次洗手；国内手卫生要求强调时机和规范揉搓步骤 | 61–64 |
| S3 | 手套破了、脏了马上换 | 原片只演示工作结束时脱卸，未讲中途破损、明显沾污时的处理 | 65–68 |
| S4 | 实验服由单位统一清洗 | 原片只说重复使用的挂到指定处；实验服带回家洗会把污染带到生活场所 | 69–70 |
| S5 | 皮肤、眼睛沾染怎么办 | 个人防护课程应与暴露后处置衔接；原片未讲冲洗、报告和就医 | 71–74 |

另在情景中设置“戴着手套摘眼镜”的错误（镜 4–5），在 K4 补“有破损就换，不凑合”（镜 15），在 K5 补“手套口盖住袖口”（镜 18），均为常规操作要求。锐器伤、口罩与面屏、感染性废物封装等内容放在本剧集 10、11 两片的补充点中，本片不重复。

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| 摘第二只手套时裸手捏手套腕部外侧，动作有歧义 | 改为手指从腕部内侧伸入翻脱（镜 26–28），错误做法打叉（镜 29） |
| 国外数值（20 秒、60% / 70%）和国外消毒产品认可体系 | 剧本不写这些数值和机构，改为“按规范”“按说明书”“规定的消毒剂” |
| “生物危害废物容器”为国外称谓 | 改称“感染性废物容器” |
| 片头出品机构标识、部门名、片尾网址 | 不使用；剧本开场与结尾由欣欣重新创作 |
| 道具上的虚构品牌（LAB-X 手套盒、EXTRA CLEAN 清洁剂） | 画面中手套盒、消毒剂瓶一律空白标签 |
| 实验服挂在“指定区域”，画面中未体现与个人衣物分开 | 剧本写明挂在实验室内、远离个人衣物（镜 37） |
