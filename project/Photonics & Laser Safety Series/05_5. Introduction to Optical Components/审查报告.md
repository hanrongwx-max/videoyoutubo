# 05_5. Introduction to Optical Components 审查报告

- 原片：5. Introduction to Optical Components（光电子技术员课程第 5 讲，讲座录屏，42 分 37 秒）；内容文档：`course/Photonics & Laser Safety Series/05_5. Introduction to Optical Components.md`
- 新剧本：《认识光学元件：材料、镀膜与滤光片》，108 镜，9 分 0 秒；原片知识点 K1–K22 全部覆盖，审查补充 S1–S5
- 总体结论：**原片不是安全教育片，而是光学元件技术讲座**，与实验室安全的相关度低—中。主体（材料热/力/化学性质、成本、镀膜工艺与膜厚监控、增透/高反/金属膜、各类滤光片）作为操作知识完整保留，用“高速路与小路”“一推一拉”“像墨镜”等比喻讲，公式、表格数值和波长参数不上屏。原片的安全内容只有截止滤光片挡有害波长和激光防护眼镜两处且较简略，改编中澄清“光路中的滤光片不能代替防护眼镜”，并补充 S1–S5。激光安全的系统讲解（激光原理、光束遮挡、光路高度等）留给本剧集第 6、8 讲的改编，本片 S 点只选与“元件、滤光、镀膜”直接相关的内容。

## 2. 内容完整性
原片完整讲了光学材料、镀膜和滤光片，但作为国内高校光学 / 激光实验室的安全教育素材，缺少下列内容，已作为 S 知识点补入剧本：

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 防护眼镜：波长和光密度都要对 | 原片只讲“按波长”，未讲光密度、标识、不得以墨镜或彩色片代替、工程措施优先；情景中阿杰拿滤光片当护目镜正是常见误区 | 84–88 |
| S2 | 激光分类与警告标志 | 原片未提激光产品分类和警示；国内按 GB 7247.1 分类标识 | 89–91 |
| S3 | 镀膜设备：高压真空，授权使用 | 原片讲溅射用高压、蒸发用电子束，但未提触电、真空、高温风险和准入授权 | 92–94 |
| S4 | 碎了的光学元件怎么处理 | 原片指出热应力可致元件破裂，碎玻璃割伤是光学实验室常见伤害 | 95–97 |
| S5 | 眼睛被照到：报告与就医 | 原片强调视网膜损伤不可逆，却没讲受照后的处置和报告 | 98–101 |

另在 K6 补“盐晶元件用干燥剂密封盒防潮保存”（镜 27），在 K15 补“镜面不要用手碰，只捏边缘”（镜 63），均为光学元件的常规做法，与第 6 讲衔接。本剧集各讲 S 点分工：本片选眼镜选择、分类标志、镀膜设备、碎玻璃、眼部受照；光路高度、首饰反射、光束终止器、清洁溶剂等留给其他讲。

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| 截止滤光片被说成可以保护技术员的眼睛，易被理解为“加片滤光片就安全” | 镜 71 熊猫明确否定：光路里的滤光片不能代替防护眼镜；情景（镜 3–6）专门演示拿彩色滤光片当护目镜是错误做法，以图标打叉 |
| 防护眼镜示例曲线（约 430 nm 以下阻挡）被说成适合紫外激光，未讲光密度 | 不引用示例波长，改为 S1 的通用选择原则 |
| 大量公式（窗口厚度、反射率、四分之一波长、T=10^-OD）和材料数值表 | 全部不上屏，改用比喻；中性密度只说“光密度越大透过越少，高一级只剩一小部分”（镜 74–75），不给百分比 |
| 背景图为光学平台上开放的红色激光光束 | 剧本所有激光器画成封闭外壳，光束进入光束收集器，不出现开放光路对着人的画面 |
| “10, 60 nanometers”“photonic slab”等转写错误 | 已在内容文档中更正；剧本不写波长数值 |
| 片头出品学院、教育中心、主讲人姓名和邮箱；滤光片镜框上的厂家品牌 | 不使用，元件一律无标识 |
