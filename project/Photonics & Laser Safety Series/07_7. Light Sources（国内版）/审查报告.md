# 07_7. Light Sources 审查报告

- 原片：7. Light Sources（光电子系列讲座第 7 讲“光源及光与人体的相互作用”，31 分 9 秒，讲座录屏）；内容文档：`course/Photonics & Laser Safety Series/07_7. Light Sources.md`
- 新剧本：《光源与光对人体的作用》，125 镜，10 分 25 秒；原片知识点 K1–K25 全部覆盖，审查补充 S1–S5
- 总体结论：**原片以专业知识为主，安全相关度中等**。前半部分是非激光光源（白炽、卤钨、荧光、HID、闪光 / 弧光灯、LED）的工作原理，后半部分是人眼和皮肤的结构与各波段的吸收部位，为下一讲激光安全做铺垫。原片指出了 HID 外壳破损紫外外泄、卤素灯高温、视网膜聚焦放大和中央凹损伤等风险，但**没有讲任何防护措施**，且“紫外大多数情况下没有其他波长危险”的说法不严谨。剧本保留全部原理类知识点（用比喻、不写公式和数值），补充光源本身的防护、高温、高压、含汞灯管破碎和眼部受照后的处置；激光分类、防护眼镜选择、光路高度等留给第 8 讲，本片不重复。

## 2. 内容完整性
原片作为光源和人眼解剖的讲座是完整的，但作为国内高校光学实验室安全教育素材，缺少下列内容，已作为 S 知识点补入剧本。为避免与本剧集其他各讲重复，本片只选与“非激光光源”直接相关的五项，激光分类、警告标志、防护眼镜按波长选择、光路高度、摘首饰、光束终止器等放在第 8 讲。

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 强光、紫外、红外光源的防护 | 原片讲了紫外外泄和各波段伤眼伤皮肤，却没讲怎么防；紫外灯、弧光灯在光学和材料实验室很常见 | 98–102 |
| S2 | 灯具高温：防烫、远离易燃物 | 原片只说卤素灯“很烫”；换灯烫伤、灯具引燃纸张溶剂是常见隐患 | 103–105 |
| S3 | 高压电源与电容放电 | 闪光灯、弧光灯（含泵浦激光器的闪光灯）电源电压高、储能电容断电后仍可能带电 | 106–109 |
| S4 | 灯管破碎：汞与玻璃碎片 | 荧光灯和 HID 灯含汞，破碎有汞蒸气和割伤风险，废灯管属危险废物 | 110–113 |
| S5 | 眼睛受照后：报告与就医 | 原片讲了损伤机理但未讲事故处置；国内要求事故及时报告、就医 | 114–118 |

另在 K11 补“外壳破损立即断电停用”（镜 45），在 K20 补“暗室里瞳孔大、进眼的光更多”（镜 78），在 K22 补“紫外也会伤角膜和晶状体”（镜 88），均为原片内容的安全引申。

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| “紫外大多数情况下没有其他波长危险”，可能让学生轻视紫外 | 改为“紫外伤眼睛前部、可见和近红外伤眼底，两者都要防”（镜 83–88），S1 专讲紫外防护 |
| 荧光灯“利用化学效应发光”的错误说法 | 按“汞放电产生紫外 → 荧光粉转成可见光”的正确原理表述（镜 25–28） |
| “光效 40%”口误、“十万倍”等数字 | 剧本不写百分比和倍数，改为定性描述（镜 32、69） |
| 原片只提“很烫”“高压触发”，未讲防护 | 补 S2、S3；所有换灯、维修画面都断电、戴手套，由授权人员操作（镜 103、108） |
| 原片未讲含汞灯管破碎 | 补 S4，不给汞的处理化学方法，只讲通风、收集、交回收 |
| 讲座录屏形式，画面为幻灯片和主讲人小窗 | 全部重画为欣欣讲解 + 情景（阿杰想徒手换刚关的卤素灯，被小研拦下）+ 比喻示意图（放大镜聚光、接力赛、单向门槛等） |
