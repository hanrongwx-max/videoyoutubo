## 2. 完整性检查（补充的 S 知识点）

原片只讲“生物恐怖是什么、有多危险”，完全没有讲在实验室 / 校园里如何识别、预防与报告。按国内高校生物安全与生物安保教育的常规要求补充：

- S1 可疑粉末 / 信件 / 包裹：不碰、不闻、不打开，离开现场、关门、就地报告（识别与处置）。
- S2 异常聚集性病例、动物异常死亡的警觉与及时上报（识别）。
- S3 生物安保：菌（毒）种与样本的上锁保藏、门禁与领用登记、不尾随，防人为盗用与滥用（预防）。
- S4 恐慌本身就是攻击目标——不信谣、不传谣，听官方通报（应对心态）。

分级方向要求：凡涉及病原危害程度 / 风险分级的视频必须说明国内病原微生物分类与国际风险组方向相反——**国内第一类最危险、第四类危害最低**，已在 K5（镜 16）明确；高致病性（第一、二类）实验活动须在相应级别实验室并经批准（镜 17）。

## 3. 不适宜内容及处理

- 武器化 / 生产 / 增强 / 投放细节：全部删除，不在内容文档摘录、不在剧本出现。
- 具体因子的可利用形式：删除，改为细菌 / 病毒 / 毒素三类的通用图标，并说明“细节不讲，记住它们很危险”（镜 22）。
- 真实事件：原片点名的真实邮件事件，改为“可疑信件 / 包裹”的通用情景，不出现名称、时间、地点。
- 危险操作展示：全片无危险操作演示；错误做法（伸手去碰可疑包裹、尾随进门）以图标 + 红叉表示（镜 28、镜 36）。
