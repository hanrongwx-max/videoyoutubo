# 05_Laser Cutter 5 xTool Studio Design Set Up 审查报告

- 原片：Laser Cutter 5: xTool Studio Design Set Up（激光切割机设计软件参数设置的屏幕录制，10 分 28 秒）；内容文档：`course/Laser Equipment & Safety Training/05_Laser Cutter 5 xTool Studio Design Set Up.md`
- 新剧本：《激光切割机：加工参数设置》，78 镜，6 分 30 秒；原片知识点 K1–K16 全部覆盖，审查补充 S1–S5
- 总体结论：**原片以软件操作为主，安全相关度中等**。其中“激光机和空气净化器都就绪才运行”“软件有预设不等于允许加工”两条安全要求讲得清楚，予以保留并强化；其余为参数设置的操作要点，全部保留但不写原片的具体功率、速度数值。作为国内高校创客空间 / 工训中心教材，补充了开机前检查、对焦与试切、含氯材料禁切、烟尘排放和全程看守。设备品牌与软件名一律改称“激光切割机”“设计软件”。

## 2. 内容完整性
原片完整讲了软件里的加工模式、材料预设、测试阵列和步骤设置，但缺少下列与本集操作直接相关的安全知识，已作为 S 知识点补入：

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 开机前检查 | 原片画面提示了蜂窝板放置，但讲解未讲；残渣、镜片污染、排风异常都是起火和设备损坏的常见原因 | 36–40 |
| S2 | 对焦与试切 | 原片放入材料后直接讲软件；焦点不准、材料翘曲会导致切不透、烧焦或撞头；测试阵列即试切，补充其安全意义 | 41–43 |
| S3 | 材料限制：含氯材料禁切 | 原片只举了硅胶、石材，未讲最危险的含氯塑料和不明成分材料 | 30–34 |
| S4 | 烟尘排放 | 原片只把净化器当作“联机条件”，未讲为什么要开、何时可开盖 | 66–68 |
| S5 | 运行时全程看守 | 测试阵列等也是真实加工，本集未提看守；明火是激光切割最常见的事故 | 69–71 |

“作品取出防烫”“设备清洁与使用登记”“故障与起火处置（119、报告）”与本集软件设置关系不大，安排在第 6 集（徽章项目实际运行）和第 7 集（收尾）。

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| 全片为某品牌设计软件界面，含设备名、净化器型号、图书馆缩写 | 画面一律为空白屏幕和图标，称“激光切割机”“设计软件”“烟尘净化器”；相关词列入 `META["avoid"]` |
| 设计中含店名标志和真人姓名 | 不使用，改为空白徽章、书签、钥匙扣图标 |
| 具体功率、速度数值 | 不写，强调按本机测试结果设置 |
| 讲解只说“硅胶、石材不安全”，没说原因与通用原则 | 改为“看许可清单”，并补充含氯、不明材料禁切（S3） |
| “fastwood”等转写错误 | 按“basswood（椴木）”理解，剧本只称“薄木板” |
