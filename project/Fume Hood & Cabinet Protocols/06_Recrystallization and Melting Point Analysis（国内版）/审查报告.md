## 2. 内容完整性
原片完整讲了重结晶与熔点测定的方法，作为国内高校化学实验安全教育素材，缺少下列内容，已作为 S 知识点补入剧本：

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 热烧杯用夹子或隔热手套 | 原片徒手（薄手套）拿热水烧杯，烫伤是重结晶最常见的伤害 | 72–75 |
| S2 | 观察保持距离，戴好护目镜 | 原片多次凑近热烧杯；热溶液可能暴沸溅出 | 76–78 |
| S3 | 先查安全说明，称粉末防扬尘 | 原片未讲化学品危害识别；固体粉末易扬尘、入眼 | 79–81 |
| S4 | 易燃溶剂：通风柜、不用明火 | 原片提本生灯；有机溶剂重结晶十分常见 | 82–84 |
| S5 | 熔点仪与熔点管防烫防扎 | 熔点仪加热块高温、毛细管易断扎手 | 85–87 |
| S6 | 烘箱干燥的注意事项 | 原片建议烘箱干燥但未讲温度和易燃溶剂风险 | 88–90 |
| S7 | 母液、滤液和碎玻璃的处置 | 原片未讲废液去向；国内要求分类收集 | 91–93 |
| S8 | 烫伤、割伤与报告 | 应急处置和报告是国内实验室安全教育的必备内容 | 94–98 |

另在 K12 补“溶剂加多了析出就少”（镜 35），在 K26 把“刮擦”明确为“轻刮内壁”（镜 66），均为常规操作说明。
