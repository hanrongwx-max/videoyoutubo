# 01_Radiation Safety Basics 审查报告

- 原片：Radiation Safety Basics（白板动画复习课，6 分 32 秒）；内容文档：`course/RSO Training Series/01_Radiation Safety Basics.md`
- 新剧本：《辐射安全基础：来源、剂量与生物效应》，86 镜，7 分 10 秒；原片知识点 K1–K16 全部覆盖，审查补充 S1–S9
- 总体结论：**原片相关度中等**。它是放射技术专业的辐射生物学复习材料，讲来源、单位、剂量限值和生物效应，概念基本正确，但以美国剂量限值和医学 X 射线摄影为背景，几乎不涉及辐射工作场所的防护操作和管理制度。剧本保留全部理论知识点（用图标和比喻讲，不写风险系数和潜伏期年数），剂量限值改为“以国家标准为准”，并补充国内法规与管理机构、防护三原则、两类效应、培训考核、个人剂量监测与职业健康检查、警告标志、时间/距离/屏蔽、怀孕告知、异常照射与事故报告。

## 2. 内容完整性
原片只有理论，没有国内高校辐射安全教育要求的管理和操作内容，已作为 S 知识点补入：

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 国内法规与学校管理机构 | 原片无任何法规和管理体系；国内用源用装置须依法许可，学校设辐射安全管理机构和人员（对应原系列的 RSO） | 53–56 |
| S2 | 防护三原则 | 原片讲了限值却没讲正当化和最优化，学员易误以为“不超限就行” | 57–59 |
| S3 | 两类效应与防护目标 | 把原片的早晚效应、有阈无阈与国标的确定性/随机性效应对上，讲清防护目标 | 60–61 |
| S4 | 先培训考核，再上岗 | 国内辐射工作人员须经培训考核 | 62–63 |
| S5 | 个人剂量监测与职业健康检查 | 原片强调“剂量会累积”，但没讲怎么监测累积剂量 | 64–67 |
| S6 | 认识电离辐射警告标志 | 入门课程必备，原片未提 | 68–69 |
| S7 | 时间、距离、屏蔽 | 外照射防护基本方法，原片未提 | 70–73 |
| S8 | 怀孕要及时告知 | 原片讲了胎儿敏感，但没讲工作人员一侧的做法 | 74–75 |
| S9 | 异常照射与事故要报告 | 事故报告是国内安全教育必备内容 | 76–79 |

另在 K2 补“限值是底线，不是额度”（镜 11），在 K15 补“风险虽低也要按规矩防护”（镜 51），与原片“小剂量也应视为有害”一致。

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| 美国剂量限值数值、rad/rem 旧单位 | 不写数值，只用戈瑞、希沃特，图示文字“以国家标准为准” |
| 画面标题 “Average Annual Dose” 与讲解“剂量限值”不一致 | 剧本只讲限值，不出现“年均剂量” |
| “Linear responses are not directly proportional” 口误（应为非线性） | 剧本明确“直线是线性，曲线是非线性”（镜 36） |
| “辐射防护剂因毒性不用于人” 过于绝对 | 只保留“某些化学物质能改变辐射反应”（镜 32） |
| 白血病相对危险 1.5、每 rad 万分之八、潜伏期 5–30 年等教材数值，未注明来源 | 不写数字，只讲“风险略有上升”“要很多年才出现”“风险虽低”（镜 46、49–51） |
| “尽可能屏蔽性腺”为患者 X 射线摄影做法，国际上对常规性腺屏蔽已有不同意见 | 剧本改为“胎儿和生殖细胞要格外保护”（镜 18），不展示对患者的具体屏蔽做法；患者防护按现行国家标准和本单位规定 |
| 遗传效应画面用成群卡通兔子和猫比喻繁殖，略显轻佻 | 改用家族树图标（镜 47） |
| 转写错误（rad、Bergonié–Tribondeau、desquamation、spermatogonia/oocytes 等） | 按正确含义改写，定律不写人名，讲成“分裂越快越敏感”（镜 17） |
