# 27_xTool MetalFab LaserWelder - Install and Set the Wire Feeder 审查报告

- 原片：… LaserWelder - Install and Set the Wire Feeder（手持式光纤激光焊接机厂家教程片段，英语旁白，3 分 46 秒）；内容文档：`course/Cleanroom & Equipment Safety/27_xTool MetalFab LaserWelder - Install and Set the Wire Feeder.md`
- 新剧本：《激光焊接机送丝机的安装与设置》，54 镜，4 分 30 秒；原片知识点 K1–K14 全部覆盖，审查补充 S1–S4
- 总体结论：**原片是厂家产品教程，不是安全片**，内容是第 26 集“连接送丝机”一节的单独剪辑。安装步骤全部保留（锁轮、电缆凸起朝上、送丝轮尺寸匹配、送丝管、焊丝盘方向、引丝不松手、穿丝、调压力、送丝与回抽、装到焊枪、微调固定），设备统称“激光焊接机”“送丝机”，厂家数值（压力表、规格）不写。第 20 集已补焊丝端头防扎伤、送丝轮防夹手，第 26 集已补衣着、长发、劳保鞋、定位红光，本集不重复，改补：插拔电缆前先关机、剪焊丝护眼、送丝时脸不对焊嘴、卡丝粘丝先停光再处理。

## 1. 法律法规与国内高校安全教育要求

| 原片内容 | 国内依据 | 结论 | 剧本处理与镜号 |
|---|---|---|---|
| 送丝机放主机左侧、锁定脚轮 | 一般机械安全常识 | 符合 | 保留（镜 7–8） |
| 连接电缆，未说明主机是否断电 | GB/T 13869-2017（以现行文本为准）《用电安全导则》；GB 4793.1-2007（以现行文本为准） | 需修改 | 情景：主机开着阿杰就插电缆（镜 3）；补 S1（镜 9–11） |
| 用钳子剪焊丝弯头，未提护眼 | 《高等学校实验室安全规范》（教科信厅函〔2023〕5 号）关于个人防护的要求；GB 14866-2023（以现行文本为准）《个人用眼护具技术要求》 | 需修改 | 补 S2：戴护目镜，断头入废料盒（镜 27–29） |
| 送丝、微调时特写正对焊嘴 | GB/T 7247.1-2024（以现行文本为准）《激光产品的安全 第 1 部分》 | 需修改 | 情景：阿杰凑近焊嘴（镜 4）；补 S3：枪口朝下、侧面观察，焊嘴是激光出口（镜 40–43） |
| 未涉及焊接中卡丝、粘丝 | GB/T 7247.1-2024（以现行文本为准）；GB/T 18490.1-2017（以现行文本为准）《机械安全 激光加工机》系列（以现行文本为准） | 需修改 | 补 S4：先松扳机、关出光，再剪丝清理（镜 47–50） |
| 压力调节表、导嘴和送丝轮规格 | 设备说明书 | 需本土化 | 保留“按说明书表格”，不写数值（镜 15、33） |
| 其余安装步骤 | 设备说明书 | 符合 | 全部保留（镜 6–46） |

## 2. 内容完整性

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 插拔电缆前先关机 | 本片唯一的电气操作是连接送丝机电缆，原片未说明断电 | 9–11 |
| S2 | 剪焊丝要护眼 | 硬质焊丝剪断时断头会弹飞，原片画面中无护目镜 | 27–29 |
| S3 | 送丝时别对着焊嘴看 | 原片特写正对焊嘴看焊丝伸出，学生容易模仿把脸凑过去 | 40–43 |
| S4 | 卡丝粘丝，先停光再处理 | 原片第 26 集提到“不下压以免粘丝”，但没讲粘丝后怎么办；这是使用中手最容易进入焊嘴前方的时刻 | 47–50 |
