# 20_Color code for Electrical Power Cable Electrical Color Code Power Cable Color Co 审查报告

- 原片：Color code for Electrical Power Cable | Electrical Color Code | Power Cable Color Code（印地语白板讲解，2 分 13 秒）；内容文档：`course/Electrical Safety Series/20_Color code for Electrical Power Cable Electrical Color Code Power Cable Color Co.md`
- 新剧本：《电线的颜色：认得清，更要验得准》，37 镜，3 分 05 秒；原片知识点 K1–K6 全部覆盖，审查补充 S1–S4
- 总体结论：**原片介绍的是印度及英国等地的旧式色标（相线红黄蓝、中性线黑），与我国现行导体色标不一致，需本土化**。剧本完整保留原片色标，但明确说明“这是一些国家和旧线路的做法”，再按国内色标讲解（三相黄绿红、中性线淡蓝、保护导体黄绿双色），并补充颜色不能代替验电、黄绿线专用、进口仪器电源线交持证电工。

## 1. 法律法规与国内高校安全教育要求

| 原片内容 | 国内依据 | 结论 | 剧本处理与镜号 |
|---|---|---|---|
| 三类导体：相线、中性线、保护导体 | 电工基本概念，无冲突 | 符合 | 镜 9–11 |

## 2. 内容完整性

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 国内导线色标 | 原片色标与我国现行规定不同，直接照搬会误导 | 19–24 |
| S2 | 颜色不能代替验电 | 旧线路、改动过的线路颜色可能不符，按颜色判断带电与否是触电常见原因 | 25–27 |
| S3 | 黄绿线只做保护接地 | 黄绿线误作相线、普通线冒充地线会使设备外壳带电 | 28–29 |
| S4 | 进口仪器电源线，交电工处理 | 高校进口仪器多，线色标准各异；学生自行换插头、改接线常见 | 30–32 |
