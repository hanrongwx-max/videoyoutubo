# 消毒与灭菌

- 剧集：高校实验室安全；对应原视频：076_消毒与灭菌（内容分析见 `course/高校实验室安全/076_消毒与灭菌.md`）
- 版本：课程
- 时长：6 分 0 秒（72 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 70 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`

## 知识点覆盖

- K1 消毒、去污、灭菌不是一回事：镜头 5、6、7、8、9
- K2 杀灭微生物的方法：热、化学、辐射：镜头 10、11、12、13
- K3 灭菌手段本身有危害，必须照规程：镜头 14、15、16、17、18
- K4 消毒剂要对得上微生物：镜头 19、20、21、22、23、24
- K5 保持湿润，等够作用时间：镜头 25、26、27、28
- K6 台面设备：开工前、收工后、洒了马上消毒：镜头 29、30、31、32、33
- K7 配制消毒液：防护、标签、按期更换：镜头 34、35、36、37、38
- K8 消毒剂不乱混，乙醇远离火源：镜头 39、40、41、42
- K9 紫外消毒只是辅助：镜头 43、44、45、46、47、48、49
- K10 湿热灭菌：靠饱和蒸汽穿透：镜头 50、51、52、53、54、55、56
- K11 灭菌效果要监测和验证：镜头 57、58、59、60、61、62
- K12 熏蒸与气体灭菌：专人操作，通风合格再进：镜头 63、64、65、66、67、68
