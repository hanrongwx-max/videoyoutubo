# 化学品储存原则与相容性

- 剧集：高校实验室安全；对应原视频：043_化学品储存原则与相容性（内容分析见 `course/高校实验室安全/043_化学品储存原则与相容性.md`）
- 版本：课程
- 时长：4 分 50 秒（58 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 56 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、老周（实验室负责人）、阿杰（本科生）、王老师（学院实验室安全管理员）

## 知识点覆盖

- K1 储存不当，就谈不上安全：镜头 5、6
- K2 按性质分类、分区存放：镜头 7、8、9、10、11
- K3 不相容物一定隔开：镜头 12、13、14、15、16
- K4 遇水危险品不与易燃液体同室：镜头 17、18、19
- S1 不按字母顺序排放（补充）：镜头 20、21、22
- K5 容器合格，与物质匹配：镜头 23、24、25、26
- K6 固定位置，阴凉通风避光：镜头 27、28、29、30
- K7 台面和通风柜不是仓库：镜头 31、32、33
- K8 放低放稳，大瓶下层配托盘：镜头 34、35、36
- S2 货架牢固，防倾倒（补充）：镜头 37、38、39
- K9 存量控制：够用就好：镜头 40、41、42、43、44
- K10 标签清楚，账物相符：镜头 45、46、47、48
- K11 经常检查储存容器：镜头 49、50、51
- K12 过期变质试剂及时清理：镜头 52、53、54、55
