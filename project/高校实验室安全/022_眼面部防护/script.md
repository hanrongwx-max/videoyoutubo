# 眼面部防护

- 剧集：高校实验室安全；对应原视频：022_眼面部防护（内容分析见 `course/高校实验室安全/022_眼面部防护.md`）
- 版本：课程
- 时长：3 分 45 秒（45 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 43 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、老周（实验室负责人）、阿杰（本科生）、王老师（学院实验室安全管理员）

## 知识点覆盖

- K1 眼睛最怕伤，护眼最划算：镜头 5、6、7、8
- K2 三类眼面防护，按用途选：镜头 9、10、11
- K3 安全眼镜防冲击，挡不住液体：镜头 12、13、14
- K4 有飞溅，戴防溅护目镜：镜头 15、16、17、18
- K5 面屏加在护目镜外：镜头 19、20、21、22
- K6 普通眼镜不能代替护目镜：镜头 23、24、25、26
- K7 化学实验室不戴隐形眼镜：镜头 27、28、29
- K8 看清标识，选合格产品：镜头 30、31、32
- K9 戴在眼睛上，全程不摘：镜头 33、34、35
- K10 各类实验的通用防护提醒：镜头 36、37、38、39
- S1 眼睛进了东西，立即冲洗（补充）：镜头 40、41、42
