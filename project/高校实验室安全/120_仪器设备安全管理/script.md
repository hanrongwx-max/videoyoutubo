# 仪器设备安全管理

- 剧集：高校实验室安全；对应原视频：120_仪器设备安全管理（内容分析见 `course/高校实验室安全/120_仪器设备安全管理.md`）
- 版本：课程
- 时长：4 分 45 秒（57 个镜头 × 5 秒）；熊猫出镜说话 3 镜，画外音 54 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、阿杰（本科生）、王老师（学院实验室安全管理员）、老李（设施工程师）

## 知识点覆盖

- K1 设备里关着危险能量：镜头 6、7、8
- K2 全生命周期管理：从验收建档到报废：镜头 9、10、11、12、13、14
- K3 先读说明书和操作规程：镜头 15、16、17
- K4 培训考核，授权上机：镜头 18、19、20、21
- K5 预约用本人账号，按规定选时段：镜头 22、23、24
- K6 使用登记、清洁交接，运行有人看：镜头 25、26、27、28
- K7 放稳擦净，定期维护和检查：镜头 29、30、31
- K8 认准检定校准标识，合格才用：镜头 32、33、34
- K9 异响异味报警，立即停机：镜头 35、36、37、38、39
- K10 故障挂牌停用，报修不私修：镜头 40、41、42、43
- K11 大型仪器的特殊警示：核磁强磁场：镜头 44、45、46、47
- K12 别让设备给你假安全感：镜头 48、49、50
- S1 特种设备：登记、检验、持证（补充）：镜头 51、52、53
