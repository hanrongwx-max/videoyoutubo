# 辐射的基本概念

- 剧集：高校实验室安全；对应原视频：085_辐射的基本概念（内容分析见 `course/高校实验室安全/085_辐射的基本概念.md`）
- 版本：课程
- 时长：5 分 25 秒（65 个镜头 × 5 秒）；熊猫出镜说话 3 镜，画外音 62 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`

- K6 天然与人工辐射源：镜头 31、32、33、34、35、36、37
- K7 本底辐射：处处都有，因地而异：镜头 38、39、40、41、42、43

- K9 放射治疗：多打病灶，少伤好细胞：镜头 50、51、52、53、54、55
- S1 依法管理：先培训，再上岗（补充）：镜头 56、57、58、59、60
