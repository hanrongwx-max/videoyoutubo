# 安全技术说明书（SDS）概述

- 剧集：高校实验室安全；对应原视频：040_安全技术说明书（SDS）概述（内容分析见 `course/高校实验室安全/040_安全技术说明书（SDS）概述.md`）
- 版本：课程
- 时长：6 分 35 秒（79 个镜头 × 5 秒）；熊猫出镜说话 3 镜，画外音 76 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、老周（实验室负责人）、阿杰（本科生）、王老师（学院实验室安全管理员）

## 知识点覆盖

- K1 化学品天天用，危害各不同：镜头 4、5、6
- K2 安全用化学品，先问三个问题：镜头 7、8
- K3 SDS：化学品的身份档案：镜头 9、10、11
- K4 旧称MSDS，现在统一叫SDS：镜头 12、13、14
- K5 旧格式乱、难懂，才有了统一制度：镜头 15、16、17、18
- K6 依法必须提供：中文安全技术说明书：镜头 19、20、21、22
- K7 每种化学品都要有一份：镜头 23、24
- K8 写给两类人：使用者和救援者：镜头 25、26
- K9 告诉你怎么用、怎么存、怎么处置：镜头 27、28、29、30
- K10 讲清四类风险：健康、火灾、反应、环境：镜头 31、32、33、34、35
- K11 了解危害第一站，操作第一依据：镜头 36、37
- K12 十六个部分，顺序固定：镜头 38、39、40、41
- K13 识别危害两件工具：说明书和标签：镜头 42、43
- K14 标签是简版，说明书是详版：镜头 44、45、46
- K15 知道放在哪，先读再用：镜头 47、48、49、50
- K16 试剂盒、清洁剂、废液也要查：镜头 51、52、53、54、55
- K17 重点读几节，再做风险评估：镜头 56、57、58
- K18 采购索取中文SDS，不全不入库：镜头 59、60、61
- K19 放在使用场所，几分钟内能调出：镜头 62、63、64
- K20 说明书要对得上、版本要新：镜头 65、66
- K21 台账和说明书联动，应急更快：镜头 67、68、69
- K22 配方可保密，安全信息不能少：镜头 70、71、72
- K23 说明书不是万能的，要会读：镜头 73、74、75、76
