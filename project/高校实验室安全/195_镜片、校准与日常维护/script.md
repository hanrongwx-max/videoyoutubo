# 镜片、校准与日常维护

- 剧集：高校实验室安全；对应原视频：195_镜片、校准与日常维护（内容分析见 `course/高校实验室安全/195_镜片、校准与日常维护.md`）

- 时长：5 分 55 秒（71 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 69 镜
