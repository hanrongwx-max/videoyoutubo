# 机械防护

- 剧集：高校实验室安全；对应原视频：126_机械防护（内容分析见 `course/高校实验室安全/126_机械防护.md`）
- 版本：课程
- 时长：5 分 0 秒（60 个镜头 × 5 秒）；熊猫出镜说话 3 镜，画外音 57 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`

## 知识点覆盖

- K1 运动部件伤人：卷入、挤压、剪切、飞出：镜头 6、7、8、9、10、11
- K2 防护装置是物理屏障，警示带代替不了：镜头 12、13、14、15、16
- K3 防护装置的类型：固定式、联锁式、可调式：镜头 17、18、19、20、21
- K4 防护装置要牢、要全、不添新危害：镜头 22、23、24、25、26
- K5 防护缺失是事故主因：不拆除、常检查：镜头 27、28、29、30、31、32、33
- K6 谁能拆、何时拆：培训授权，先上锁挂牌：镜头 34、35、36、37、38、39
- K7 防卷入：束发扎袖，不戴手套碰旋转件：镜头 40、41、42、43、44
- K8 急停会用，断电后等完全停稳：镜头 45、46、47、48、49、50、51
- K9 设备运动区域不进入：镜头 52、53、54、55、56
