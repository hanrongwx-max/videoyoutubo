# 访客与外来人员管理

- 剧集：高校实验室安全；对应原视频：008_访客与外来人员管理（内容分析见 `course/高校实验室安全/008_访客与外来人员管理.md`）
- 版本：课程
- 时长：5 分 20 秒（64 个镜头 × 5 秒）；熊猫出镜说话 3 镜，画外音 61 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、老周（实验室负责人）、阿杰（本科生）、王老师（学院实验室安全管理员）、老李（设施工程师）

- K6 不靠、不搭、不爬：镜头 27、28、29
- K7 留意会突然启动的设备：镜头 30、31、32、33
- K8 先说清楚，再动手：镜头 34、35、36
- K9 拍照拍视频有边界：镜头 37、38、39
- S1 高风险区域限制进入（补充）：镜头 40、41、42
- S2 紧急时带访客撤离（补充）：镜头 43、44、45
- K10 外来维修人员：双向告知危险：镜头 46、47、48
- K11 外来人员作业前：清场、去污、陪同：镜头 49、50、51、52、53
- K12 社团活动：先审批，定安全负责人：镜头 54、55、56
- K13 社团借用实验室：先培训准入：镜头 57、58、59、60
