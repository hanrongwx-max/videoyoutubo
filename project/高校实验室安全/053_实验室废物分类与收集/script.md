# 实验室废物分类与收集

- 剧集：高校实验室安全；对应原视频：053_实验室废物分类与收集（内容分析见 `course/高校实验室安全/053_实验室废物分类与收集.md`）
- 版本：课程
- 时长：6 分 0 秒（72 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 70 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、老周（实验室负责人）、阿杰（本科生）、王老师（学院实验室安全管理员）

## 知识点覆盖

- K1 废物管理是实验安全的一环：镜头 5、6、7、8
- K2 动手之前，先想好废物怎么处置：镜头 9、10、11、12
- K3 实验室废物分几类，分开收：镜头 13、14、15、16、17
- K4 从源头减量，剩余试剂别浪费：镜头 18、19、20、21
- K5 下水道不是废液桶：镜头 22、23、24、25、26
- K6 按性质分类收集，不相容不混装：镜头 27、28、29、30、31
- K7 实验各环节的废液都要收：镜头 32、33、34、35、36
- K8 含卤、含重金属的废液单独收：镜头 37、38、39、40、41
- K9 每次倒之前，先看标签再记录：镜头 42、43、44
- K10 容器相容耐腐蚀，放托盘、不装满：镜头 45、46、47、48
- K11 标签写全，随手盖紧：镜头 49、50、51、52、53
- K12 倒废液做好防护，不靠挥发处理：镜头 54、55、56
- K13 空瓶、手套、滤纸也是危险废物：镜头 57、58、59、60、61
- K14 废电池和电子废件回收：镜头 62、63、64、65
- K15 废液桶异常：停加、远离、报告：镜头 66、67、68
