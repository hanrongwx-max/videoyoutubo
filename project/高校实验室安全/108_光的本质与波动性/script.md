# 光的本质与波动性

- 剧集：高校实验室安全；对应原视频：108_光的本质与波动性（内容分析见 `course/高校实验室安全/108_光的本质与波动性.md`）
- 版本：课程
- 时长：6 分 0 秒（72 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 70 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`

## 知识点覆盖

- K1 光就在身边：光子学是用光的技术：镜头 5、6、7、8
- K2 光是电磁能，有波粒二象性：镜头 9、10、11、12、13
- K3 波的基本量：振幅、波长、周期、频率：镜头 14、15、16、17、18、19
- K4 光速恒定：波长越短频率越高：镜头 20、21、22、23、24
- K5 光是横波：电场磁场垂直振动：镜头 25、26、27、28
- K6 电磁波谱：人眼只见400到700纳米：镜头 29、30、31、32、33
- K7 折射率：光进介质变慢，频率不变：镜头 34、35、36、37
- K8 相位与相干：激光步调一致：镜头 38、39、40、41、42、43
- K9 反射定律：反射角等于入射角：镜头 44、45、46、47、48
- K10 折射定律：换介质光会拐弯：镜头 49、50、51、52、53
- K11 干涉：峰峰加强，峰谷抵消：镜头 54、55
- K12 衍射：光绕过边缘分成多束：镜头 56、57、58、59、60
- K13 偏振：电场振动的方向：镜头 61、62、63、64、65、66
- S1 学光学基础，是为了看懂光的危险（补充）：镜头 67、68、69
