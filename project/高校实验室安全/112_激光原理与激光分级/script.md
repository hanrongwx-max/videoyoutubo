# 激光原理与激光分级

- 剧集：高校实验室安全；对应原视频：112_激光原理与激光分级（内容分析见 `course/高校实验室安全/112_激光原理与激光分级.md`）
- 版本：课程
- 时长：5 分 0 秒（60 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 58 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`

## 知识点覆盖

- K1 功率越高，越要讲激光安全：镜头 5、6、7
- K2 激光怎样产生：激励、受激辐射与谐振腔：镜头 8、9、10、11、12、13、14
- S1 激光的特点与常见激光器（补充）：镜头 15、16、17、18、19、20
- K3 激光安全标准：国内看国家标准：镜头 21、22、23、24
- K4 按危害分级：先看标签上的级别：镜头 25、26、27、28、29、30、31、32
- K5 1类与1M类：正常使用无危害：镜头 33、34、35、36
- K6 2类与2M类：别盯着看：镜头 37、38、39、40、41
- K7 3R类：别直视，别用望远镜看：镜头 42、43、44、45
- K8 3B类：直射和镜面反射都伤眼：镜头 46、47、48、49、50
- K9 4类：漫反射也伤人，还能引燃：镜头 51、52、53、54、55、56
