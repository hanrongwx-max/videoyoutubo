# 气瓶的标识与瓶阀

- 剧集：高校实验室安全；对应原视频：130_气瓶的标识与瓶阀（内容分析见 `course/高校实验室安全/130_气瓶的标识与瓶阀.md`）
- 版本：课程
- 时长：4 分 50 秒（58 个镜头 × 5 秒）；熊猫出镜说话 3 镜，画外音 55 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、老周（实验室负责人）、阿杰（本科生）

## 知识点覆盖

- K1 气瓶必须标识清楚，会读标记是基本功：镜头 6、7、8
- K2 国内气瓶颜色标志：瓶色、字样、色环：镜头 9、10、11、12、13
- K3 认气体：看字样和标签，不只看颜色：镜头 14、15、16、17、18
- K4 没有标签、标识不清，坚决不用：镜头 19、20、21、22
- K5 瓶肩钢印：气瓶的身份证：镜头 23、24、25、26、27
- K6 检验标记：在有效期内才能用：镜头 28、29、30、31、32、33、34
- K7 用前三查：标识、检验期、外观：镜头 35、36、37、38、39
- K8 瓶阀是关键安全部件，不拆不修：镜头 40、41、42、43、44、45
- K9 出气口按气体区分，防止接错：镜头 46、47、48、49
- K10 安全泄压装置不许拆改：镜头 50、51、52、53、54
