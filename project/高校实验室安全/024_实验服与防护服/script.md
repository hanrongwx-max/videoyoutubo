# 实验服与防护服

- 剧集：高校实验室安全；对应原视频：024_实验服与防护服（内容分析见 `course/高校实验室安全/024_实验服与防护服.md`）
- 版本：课程
- 时长：3 分 45 秒（45 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 43 镜

## 知识点覆盖

- K1 实验服是防护用品，进门就穿：镜头 5、6、7、8
- K2 实验服选棉质或阻燃材质：镜头 9、10、11、12
- K3 明火、自燃试剂和火花：穿阻燃服：镜头 13、14、15、16、17、18
- K4 扣子扣好，袖口塞进手套：镜头 19、20、21、22
- K5 有喷溅，加穿耐化学品围裙：镜头 23、24、25、26、27
- K6 防护服按危害选，沾污就换：镜头 28、29、30、31、32
- K7 实验服不出实验室，不带回家洗：镜头 33、34、35、36、37、38
- S1 大量沾染，立即脱下冲洗（补充）：镜头 39、40、41、42
