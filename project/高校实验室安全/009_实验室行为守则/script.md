# 实验室行为守则

- 剧集：高校实验室安全；对应原视频：009_实验室行为守则（内容分析见 `course/高校实验室安全/009_实验室行为守则.md`）
- 版本：课程
- 时长：5 分 55 秒（71 个镜头 × 5 秒）；熊猫出镜说话 3 镜，画外音 68 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、老周（实验室负责人）、阿杰（本科生）、老李（设施工程师）

- K6 守则堵住的是暴露途径：镜头 27、28、29
- K7 不吃、不喝、不吸烟、不化妆：镜头 30、31、32、33、34
- K8 实验冰箱和微波炉不碰食品：镜头 35、36、37
- K9 不用手碰，不闻不尝：镜头 38、39
- K10 专心操作，不嬉闹：镜头 40、41、42、43
- K11 别人的样品先问再动，公用器具用完归位：镜头 44、45、46、47、48
- S1 不私自改装仪器设备（补充）：镜头 49、50、51
- K12 危险实验不独自做：镜头 52、53、54、55、56
- K13 夜间节假日实验先报备，不疲劳作业：镜头 57、58、59、60
- K14 无人值守实验：经同意，挂牌留联系方式：镜头 61、62、63、64
- K15 离开前检查水电气门窗：镜头 65、66、67
