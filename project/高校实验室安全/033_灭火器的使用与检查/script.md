# 灭火器的使用与检查

- 剧集：高校实验室安全；对应原视频：033_灭火器的使用与检查（内容分析见 `course/高校实验室安全/033_灭火器的使用与检查.md`）
- 版本：课程
- 时长：4 分 45 秒（57 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 55 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、阿杰（本科生）、王老师（学院实验室安全管理员）、老李（设施工程师）

## 知识点覆盖

- K1 先培训，人人会用灭火器：镜头 4、5、6
- K2 听老师安排，自己也要会：镜头 7、8、9
- K3 动手前先问三个问题：镜头 10、11、12、13
- K4 使用四步：提、拔、握、压：镜头 14、15、16、17、18、19
- K5 对准火焰根部，左右扫射：镜头 20、21、22、23
- K6 一具灭火器只能喷很短时间：镜头 24、25、26
- K7 保持安全距离，站在上风：镜头 27、28、29、30
- K8 背对出口，退路留在身后：镜头 31、32、33
- K9 二氧化碳灭火器：防冻伤，防窒息：镜头 34、35、36
- K10 扑不灭就撤，生命高于财产：镜头 37、38、39、40
- K11 灭火器的日常检查：镜头 41、42、43、44、45、46、47、48
- K12 放在明处，不挡不挪，用后更换：镜头 49、50、51、52、53、54
