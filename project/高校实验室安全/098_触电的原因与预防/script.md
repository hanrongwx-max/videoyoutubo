# 触电的原因与预防

- 剧集：高校实验室安全；对应原视频：098_触电的原因与预防（内容分析见 `course/高校实验室安全/098_触电的原因与预防.md`）
- 版本：课程
- 时长：6 分 0 秒（72 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 70 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、老周（实验室负责人）、阿杰（本科生）、王老师（学院实验室安全管理员）、老李（设施工程师）

- K11 好习惯：单手操作、按要求穿戴：镜头 47、48、49
- K12 先培训：会识别、会避开：镜头 50、51、52
- K13 认清总闸和急停，起火也先断电：镜头 53、54、55、56
- K14 有人触电：先断电，不徒手拉：镜头 57、58、59、60、61
- K15 断不了电：用干燥绝缘物挑开：镜头 62、63、64、65
- K16 脱离电源后：急救、就医、报告：镜头 66、67、68、69
