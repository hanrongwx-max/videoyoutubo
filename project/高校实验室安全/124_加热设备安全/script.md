# 加热设备安全

- 剧集：高校实验室安全；对应原视频：124_加热设备安全（内容分析见 `course/高校实验室安全/124_加热设备安全.md`）
- 版本：课程
- 时长：5 分 15 秒（63 个镜头 × 5 秒）；熊猫出镜说话 3 镜，画外音 60 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、阿杰（本科生）、保卫处值班员

## 知识点覆盖

- K1 加热不离人，不过夜无人加热：镜头 6、7、8、9、10、11
- K2 易燃溶剂不用明火，热源旁不放易燃物：镜头 12、13、14、15
- K3 电热板和加热套：查电线、离热面：镜头 16、17、18、19、20
- K4 加热液体防暴沸，不加热密闭容器：镜头 21、22、23、24、25
- K5 水浴油浴：控温看守，防过热：镜头 26、27、28、29、30
- K6 烘箱：易燃物和湿溶剂样品不进：镜头 31、32、33、34、35
- K7 马弗炉等高温炉：有人值守，防烫防火：镜头 36、37、38、39
- K8 实验室微波炉：只做实验，不放金属和密闭容器：镜头 40、41、42、43
- K9 燃气灯和热风枪：查管、不对人：镜头 44、45、46、47、48
- K10 热物看不出来：用对钳子和隔热手套：镜头 49、50、51、52、53
- K11 关了也烫：降温再开，热物放耐热面：镜头 54、55、56、57
- S1 当心高温表面：标识和提示（补充）：镜头 58、59
