# 动火作业

- 剧集：高校实验室安全；对应原视频：139_动火作业（内容分析见 `course/高校实验室安全/139_动火作业.md`）

- 时长：5 分 15 秒（63 个镜头 × 5 秒）；熊猫出镜说话 3 镜，画外音 60 镜
