# 通风柜的正确使用

- 剧集：高校实验室安全；对应原视频：052_通风柜的正确使用（内容分析见 `course/高校实验室安全/052_通风柜的正确使用.md`）
- 版本：课程
- 时长：6 分 0 秒（72 个镜头 × 5 秒）；熊猫出镜说话 2 镜，画外音 70 镜
- 依据：新课程《高校实验室安全》：由全部原视频的知识点合并整理（K），按国内法规和高校实验室安全教学要求编写，必要时补充知识点（S）；知识点来源见 `来源.tsv`，教案见 `course/高校实验室安全/`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、老周（实验室负责人）、阿杰（本科生）、王老师（学院实验室安全管理员）、老李（设施工程师）

## 知识点覆盖

- K1 装好只是一半，用对才完整：镜头 5、6、7
- K2 有害、挥发、易燃加热的操作进柜做：镜头 8、9、10、11、12、13、14
- K3 用前自检：开风机、看气流、看标识：镜头 15、16、17、18、19、20
- K4 柜内操作也要穿戴防护：镜头 21、22、23
- K5 视窗拉到标线以下：镜头 24、25、26、27、28、29、30
- K6 站着操作，头不伸进柜内：镜头 31、32、33、34、35
- K7 在柜内深处操作：镜头 36、37、38、39
- K8 动作轻缓，材料一次放齐：镜头 40、41、42、43、44
- K9 不堆放、不挡风口，不当储存柜：镜头 45、46、47、48、49、50、51
- K10 易燃物远离热源，不敞放废液：镜头 52、53、54、55
- K11 不擅自改动通风柜：镜头 56、57、58
- K12 报警或停风：停、盖、关、撤、报：镜头 59、60、61、62、63、64
- K13 用完清理，关闭视窗：镜头 65、66、67、68
