## 2. 内容完整性
原片覆盖了气瓶全流程，但作为国内高校实验室安全教育素材，缺少下列内容，已作为 S 知识点补入剧本：

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 气瓶是特种设备 | 原片无国内法规；国内气瓶按特种设备管理，须在检验有效期内使用，从有资质单位购气，实验室气瓶数量控制在必要范围 | 90–93 |
| S2 | 国内颜色标志与状态牌 | 原片称颜色不可靠，与国内 GB/T 7144-2016（以现行文本为准） 统一颜色标志不一致；原片画面出现 EMPTY / PART FULL / FULL 吊牌却未讲解，国内实验室普遍要求挂满瓶、使用中、空瓶状态牌并分区存放 | 94–96 |
| S3 | 气体报警与通风 | 可燃、有毒气体泄漏和低温液体致缺氧是气瓶事故主要后果；高校检查要求配备气体报警装置、氧含量监测和气瓶柜 | 97–99 |
| S4 | 有毒气体从严管理 | 原片只提有毒气体气瓶无泄压装置；国内有毒气体按危险化学品管理，剧毒的另有严格规定 | 100–101 |
| S5 | 用毕关阀，留有余压 | 国内气瓶使用的基本要求：用完关阀、不得用尽、开阀站侧面缓开、氧气瓶严禁沾油，原片均未讲 | 102–105 |
| S6 | 泄漏应急与报警报告 | 原片只说“通知主管”；需补充可燃气体泄漏的禁忌、119/120 和逐级报告 | 106–109 |

另在情景（镜 3–6）用“气瓶未固定靠在桌边”引出固定要求；在 K14 把“氧化性气体”说成“助燃气体”，便于理解。

## 3. 不适宜内容

| 原片问题 | 剧本处理 |
|---|---|
| 英制数值：一瓶氢气可充满的房间体积、液化压力范围（psi）、低温液体温度（°F）、可燃与氧化性气体相隔英尺数、存放月数 | 剧本一律不写数值，“psi”“Fahrenheit”“feet” 列入 `META["avoid"]` |
| “不能凭颜色判断”与国内 GB/T 7144-2016（以现行文本为准） 不一致 | 改为“颜色只作辅助，认准字样标签”（镜 39、95） |
| CGA 为美国规格名称 | 剧本称“接头”，不出现 CGA |
| 反例演示：拖拽、手滚、撕标签、伸手接倒瓶、日晒存放（原片已打红叉） | 一律用图标表示并打叉（镜 32、38、42–43、50），不让角色示范错误动作；情景中阿杰的错误为“未固定”，由小研纠正 |
| 气瓶倒地滚动、阀门喷气的实拍 | 改为“气瓶变火箭”的示意图（镜 27），不展示真实事故画面 |
| 部分搬运镜头未见安全鞋、手套 | 剧本搬运镜头中老李穿安全鞋、戴手套（镜 21、44） |
| 片头片尾出品方标志、全片预览水印；气体供应商、标签印制商、绑带、减压器、通风橱品牌 | 不使用；标签、合格证、状态牌一律空白或只有象形图 |
| 转写错误 “buns and burners” | 内容文档注明应为 Bunsen burners，剧本写“燃烧器” |
