- 原片：How to test for peroxides using Quantofix dip strips（过氧化物试纸检测演示，1 分 39 秒）；内容文档：`course/Laboratory Equipment Safety Series/07_How to test for peroxides using Quantofix dip strips.md`

- 总体结论：**原片是化学品安全管理的操作演示，相关度高**，通风橱内操作、防护、取用试纸、避免污染试剂、按说明书加水、比色、标签记录、试纸有效期讲得清楚。缺口在“为什么查”和“查出问题怎么办”：易形成过氧化物化学品的危险、日期管理、可疑容器不开不动先报告、超限后停用并按危险废物处置。**剧本只讲到安全管理层面**：测试步骤按说明书和本校规程，不写等待时间、浓度限值、检测周期，不涉及过氧化物的去除或处理方法；试纸品牌、货号已列入 `META["avoid"]`。
