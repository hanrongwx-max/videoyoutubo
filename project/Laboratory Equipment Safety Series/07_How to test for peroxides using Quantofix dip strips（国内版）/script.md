# 过氧化物试纸检测（国内版）

- 剧集：Laboratory Equipment Safety Series；对应原视频：07_How to test for peroxides using Quantofix dip strips（内容分析见 `course/Laboratory Equipment Safety Series/07_How to test for peroxides using Quantofix dip strips.md`）
- 版本：国内版；原著版见 `../07_How to test for peroxides using Quantofix dip strips/`
- 时长：3 分 30 秒（42 个镜头 × 5 秒）；熊猫出镜说话 5 镜，画外音 37 镜
- 依据：原视频知识点（K）+ 审查补充知识点（S），按国内法规和高校实验室安全教育要求改编；审查记录见 `审查报告.md`
- 角色：欣欣（熊猫主持）、小研（研究生，兼实验室安全员）、阿杰（本科生）、保卫处值班员

- K1 用试纸查过氧化物：镜头 4

- K4 非废液，另取少量来测：镜头 10、11、12
- K5 甩去余液，按时等待：镜头 13
- K6 测有机溶液，别漏加水步骤：镜头 14、15、16
- K7 水溶液也照样做：镜头 17
- K8 对照比色卡读结果：镜头 18、19
- K9 在专用标签上记录：镜头 20
- K10 试纸过期要更换：镜头 21
- K11 标签上的警示：镜头 22、23、24
- S1 为什么要查过氧化物（补充）：镜头 25、26、27
- S2 收货、开封都写日期（补充）：镜头 28、29、30
- S3 可疑容器：不开、不动、先报告（补充）：镜头 31、32、33、34、35
- S4 超限停用，按危废处置（补充）：镜头 36、37、38
