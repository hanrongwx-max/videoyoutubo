# 01_Laboratory Safety Using a Centrifuge 审查报告

- 原片：Laboratory Safety: Using a Centrifuge（离心机安全短片，2 分 0 秒）；内容文档：`course/Laboratory Equipment Safety Series/01_Laboratory Safety Using a Centrifuge.md`
- 新剧本：《安全使用离心机》，48 镜，4 分 0 秒；原片知识点 K1–K12 全部覆盖，审查补充 S1–S5
- 总体结论：**原片是离心机安全入门短片，相关度高**，个人防护、称重配平、配平管、装载检查、稳固台面、晃动停机、停稳开盖讲得清楚准确。作为国内高校教材，主要缺口是：准入培训与额定转速、生物样品密封离心、运行守候与异常时远离、破管溢漏处置、事故报告与人员暴露处理。另将原片“晃动就拔插头”调整为“先按停止键、必要时切断电源、人员远离”。

## 2. 内容完整性

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 先培训，认准转子和额定转速 | 国内高校要求先培训后使用；超速、超载是离心事故的主要原因之一，原片未讲 | 30–32 |
| S2 | 生物样品：密封离心 | 原片画面使用血液样品，却未讲气溶胶防护 | 33–35 |
| S3 | 守到平稳，异常时远离 | 原片只讲停机，未讲守候、远离和禁止强行刹停 | 36–38 |
| S4 | 破管和溢漏的处置 | 最常见的离心意外，原片未讲，存在割伤和污染风险 | 39–41 |
| S5 | 事故报告与人员暴露 | 国内高校安全教育必备内容 | 42–44 |

另在 K4 补“多支管子两两对称”（镜 13），为常规操作要求。
