- 原片：Colour Code of Web Sling || SWL of Web Sling（吊装带颜色代码与安全工作载荷，幻灯片录屏，2 分 01 秒）；内容文档：`course/ACS Hazard Communication & Safety/10_Colour Code of Web Sling SWL of Web Sling.md`

## 2. 内容完整性
原片内容极少，作为高校安全教育素材补充以下 S 知识点（S2、S3 按改编要求加入；S4、S5 为实验室日常相关内容，与本系列 05–09 号补充内容不重复）：

| 编号 | 补充知识点 | 原因 | 镜号 |
|---|---|---|---|
| S1 | 吊装带用前先检查 | 原片只讲能吊多重，未讲损伤即停用；吊带断裂是吊装事故的直接原因之一 | 18–20 |
| S2 | 起重作业须持证 | 起重机械作业人员持证是法定要求；高校大型设备吊装须由有资质单位实施 | 21–24 |
| S3 | 吊装区域不站人 | 高校师生最可能的风险是从吊装现场穿行；吊物下方站人是严禁行为 | 25–27 |
| S4 | 实验室里的重物搬运 | 实验室人员常搬运成箱试剂、仪器部件，腰背扭伤和砸伤常见 | 28–32 |
| S5 | 气瓶搬运用专用推车 | 气瓶是实验室最常见的重物，滚动、拖拽、不固定易导致倾倒和阀门损坏 | 33–35 |
