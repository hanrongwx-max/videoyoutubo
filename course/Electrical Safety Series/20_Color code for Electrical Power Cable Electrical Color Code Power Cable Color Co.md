## 内容概要
本片介绍电力电缆的“基本色标”。先说明了解色标很重要，然后用一张表格逐行填写：导体分为相线（Line）、中性线（Neutral）和保护导体（地线，Earth）三类；单相线路的相线可以是红、黄或蓝色之一；三相线路 Line 1 红、Line 2 黄、Line 3 蓝，简称 RYB；中性线为黑色；保护导体为黄绿双色。右侧始终配一束彩色电线照片。最后缩小表格，重写标题道别。原片所讲是印度及英国等地的旧式色标；我国现行规定为三相 L1 黄、L2 绿、L3 红，中性线淡蓝色，保护导体黄绿双色（以现行标准为准）。

## 安全要点与原片的不足
1. **色标与我国不一致**：原片的“红黄蓝相线、黑色中性线”是印度及英国等地的旧式色标。我国现行导体色标（GB 7947《人机界面标志标识的基本和安全规则 导体颜色或字母数字标识》，版本以现行文本为准；建筑电气施工验收也有相应要求）为：三相交流 L1 黄、L2 绿、L3 红；中性线（N）淡蓝色；保护导体（PE）黄绿双色。单相设备电源线常见为棕色（相线）、蓝色（中性线）、黄绿（PE）。剧本保留原片色标作为“有的国家和旧线路的做法”，以国内色标为准讲解。
2. **只讲颜色，不讲安全意义**：没有说明“颜色只是标识，不能代替验电”——旧线路、进口设备、私自改动的线路颜色可能不符合标准，动手前必须由持证电工断电并验电。
3. **未强调黄绿双色线的专用性**：黄绿双色只能用作保护导体，不得作相线或中性线，任何导线也不得冒充地线。
4. **未讲进口仪器电源线**：进口仪器、旧仪器的电源线色标可能不同，更换插头或改接须交持证电工，学生不得自行接线。
5. **转写错误**：face → phase；RYBB → RYB。
6. **出镜信息**：频道名 HSE STUDY GUIDE；彩色电线照片为图库素材。卡通改编不使用。
