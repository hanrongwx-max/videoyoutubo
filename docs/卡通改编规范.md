# 安全教学视频分析与卡通改编规范

适用于本仓库 Release 附件中的全部安全教学视频（清单 `tools/assets.tsv`，25 个剧集、441 个视频）。
卡通的画风、角色和制作方法沿用 [hanrongwx-max/ppplus107](https://github.com/hanrongwx-max/ppplus107)，提示词拼装代码同步在 `tools/cartoon/style.py`、`tools/cartoon/sign_catalog.py`。

## 一、流程与目录

| 步骤 | 命令 / 产物 |
|---|---|
| 1. 附件清单 | `python3 tools/manifest.py` → `tools/assets.tsv`（剧集、序号、视频名称、原标题、附件 ID） |
| 2. 分析素材 | `python3 tools/analyze_video.py --series "<剧集>" [--only 01 02]` → `work/<剧集>/<视频名称>/`（转写、镜头切分、关键帧、拼图；不入库） |
| 3. 视频内容文档 | `course/<剧集>/<视频名称>.md`（人工 / 模型看拼图和转写后编写，模板见第二节） |
| 4. 卡通剧本作者源 | `project/<剧集>/<视频名称>/src.py`（规则见第三节） |
| 5. 审查报告 | `project/<剧集>/<视频名称>/审查报告.md`（模板见第四节） |
| 6. 制作包 | `python3 tools/cartoon/build_project.py` → 同目录 `shots.json` `script.md` `subtitles.srt` `overlay.srt` `prompts.json` `source_map.json` `workflow.md` `comfyui/` |
| 7. 生成与拼接 | `tools/cartoon/generate.py`（ComfyUI + MiniMax H3）→ `tools/cartoon/assemble.py` |

**两个版本（用户要求，2026-10-31）**：原视频内容与国内法律法规有区别时，同一视频出两版卡通剧本——
- 原著版 `project/<剧集>/<视频名称>/`：`META["edition"] = "原著版"`，只有原片知识点 K*，内容、做法、数值、法规与原片完全一致（**完全照原片**，错误也不改不标），不写审查报告；编写说明见 `docs/handoff/original_brief.md`。
- 国内版 `project/<剧集>/<视频名称>（国内版）/`：按第三、四节改编（本土化、补充知识点 S*、`审查报告.md`），片名自动加“（国内版）”。
- 与国内要求完全一致的视频只有一版，放在 `project/<剧集>/<视频名称>/`。
- 两版都遵守版权规则（旁白重写、固定卡通角色、原机构/品牌/人名入 avoid）和生物安保底线。
- 编写者先按原流程写到 `project/<剧集>/<视频名称>/`，`python3 tools/split_editions.py` 会把已提交的改编剧本改名为国内版；`--todo` 列出待写原著版的视频。

视频名称 = `两位序号_原标题`（去掉系列后缀和文件名非法字符），与 `tools/assets.tsv` 的“视频名称”列一致。

## 二、视频内容文档模板（course/<剧集>/<视频名称>.md）

```markdown
# <视频名称>

## 基本信息
| 项目 | 内容 |
|---|---|
| 剧集 | ... |
| 原标题 / 链接 | ... |
| 时长、分辨率 | ... |
| 语言 | ... |
| 类型 | 讲解 / 操作演示 / 情景剧 / 动画 / 讲座录屏 …… |
| 适用对象 | ... |
| 与“实验室安全”主题的相关度 | 高 / 中 / 低（低时说明原因，例如本片是实验技术或科研讲座） |

## 内容概要
3–6 句话说明本片讲什么、怎么讲。

## 知识点
编号 K1、K2……，每条一句话，后附出现时间。卡通剧本必须全部覆盖。

## 讲解内容（逐段）
按时间分段，每段写：时间范围、讲解要点（中文转述）、原话摘录（关键句，英文原文，不超过两句）。

## 画面文字（字符）
片头片尾字幕、屏幕标题、标签、警示牌、仪器面板上能看清的文字，按时间列出；看不清的写“不可辨认”。

## 镜头说明
| 镜头 | 时间 | 画面内容 | 景别 / 运镜 | 同期讲解 |
按 `work/.../shots.json` 的镜头切分逐镜填写（相邻、内容相同的镜头可合并为一行并注明镜号范围）。

## 安全要点与原片的不足
原片明显的错误、过时做法、与国内要求不一致之处、缺失的知识点（供审查报告引用）。
```

原话摘录只用于教学分析和改编依据，单条不超过两句；不得整段翻译成新剧本的旁白。

## 三、卡通剧本规则（src.py，`build_project.py` 校验）

与 ppplus107 一致：

- 每镜 5 秒，旁白不超过 20 字（不含标点），一句话说完；全片 2–15 分钟。
- 英文画面写给 MiniMax H3，不能有中文；出现 `panda mascot` 的镜头由熊猫对镜说话，其余为画外音。
- 角色只用固定角色：欣欣（`panda mascot`）、小研（`female graduate student`）、老周（`older man`）、阿杰（`young male student`）、
  王老师（`safety administrator`）、老李（`facility engineer`）、保卫处值班员（`security officer`）。英文画面里用这些英文称呼。
- 画面不出文字：卡片、标签、屏幕、表单一律空白或只有图标；需要汉字时写进第 6 项“图示文字”（每镜最多 5 个、每个不超过 8 字，拼接时叠加）。
  标识写英文名称（如 `biohazard warning sign`、`eyewash sign`），生成时自动套国家标准式样。
- 结构：开场（1–2 镜，熊猫出镜报题）→ 情景导入（阿杰等人遇到问题）→ 各知识点讲解（顶部文字写知识点名）→ 小结 → 结尾（唯一一镜）。
- 知识点编号：原片知识点 K1…（与内容文档一致，全部覆盖、不删减讲解内容），审查补充的知识点 S1…。
- 不展示危险操作细节、配方、参数或安保薄弱点；错误做法用图标表示并打叉。数字电话 119、120 写阿拉伯数字（生成时按位读）。

## 四、审查要求（审查报告.md）

### 1. 法律法规与高校安全教育要求
逐条对照（按本片涉及的领域选用），写明“符合 / 需修改 / 需本土化”和改法：

- 通用：《中华人民共和国安全生产法》《中华人民共和国消防法》、教育部《高等学校实验室安全规范》（教科信厅函〔2023〕5 号）及高校实验室安全检查项目表、
  学校实验室准入和安全培训制度、三级管理（学校—学院—实验室）与实验室负责人第一责任。
- 化学品：《中华人民共和国危险化学品安全法》（2026 年 5 月 1 日起施行）及《危险化学品安全管理条例》（以现行文本为准）、GB 30000 系列（GHS 分类和标签）、GB 15603-2022（以现行文本为准）（危险化学品仓库储存通则）、《易制毒化学品管理条例》、
  剧毒品“五双”管理、《易制爆危险化学品治安管理办法》、《国家危险废物名录》与危险废物不得倒入下水道。
- 生物：《中华人民共和国生物安全法》、《病原微生物实验室生物安全管理条例》、GB 19489-2008（以现行文本为准）《实验室 生物安全通用要求》、
  WS 233-2017《病原微生物实验室生物安全通用准则》、《人间传染的病原微生物目录》（国家卫生健康委 2023 年版）、医疗废物与感染性废物管理。
- 辐射：《中华人民共和国放射性污染防治法》、《放射性同位素与射线装置安全和防护条例》、GB 18871-2002（以现行文本为准）（剂量限值、电离辐射标志）、辐射安全培训与个人剂量监测。
- 激光：GB/T 7247.1-2024（以现行文本为准）（激光产品的安全 第 1 部分），激光分类与防护眼镜选择。
- 电气：GB 4793.1-2007（以现行文本为准）（测量、控制和实验室用电气设备的安全要求）、电工作业持证上岗、漏电保护。
- 气瓶与低温：《特种设备安全法》、TSG 23《气瓶安全技术规程》、GB/T 7144-2016（以现行文本为准） 气瓶颜色标志、液氮等低温液体窒息与冻伤防护。
- 消防与应急：GB 2894-2025（以现行文本为准） 安全标志、GB 13495.1-2015（以现行文本为准） 消防安全标志、火警 119、急救 120、事故报告程序（先报告实验室负责人、学院和保卫处）。

国外制度（OSHA、CDC/NIH BMBL、NRC 等）只作背景，不给国外的数值、阈值和豁免条件；国内的条款号、数值没有核对原文的，写“以现行文本和本校规定为准”，不写入剧本。

### 2. 内容完整性
对照该主题国内高校安全教育的常规要求，列出原片缺失的知识点，作为 S 知识点补进剧本（例如：准入培训、风险评估、个人防护、应急处置、废物处置、事故报告）。

### 3. 不适宜内容
原片中不安全的示范（如未戴防护、单手操作、错误的应急方式）、与国内规定冲突的做法、过时的标识和设备，写明在剧本中如何处理。
与安全无关的内容（纯实验技术、科研讲座）保留其中的操作要点，并补充相关安全知识。

### 4. 版权处理
- 新剧本的旁白、情节、画面全部重新创作：只保留知识点（事实和方法不受著作权保护），不翻译、不照搬原片的讲稿、台词、情节、画面构图和片头片尾；
- 不使用原片的机构名、品牌、型号、主持人、商标和音乐（`build_project.py` 自动检查常见名称，本片特有的在 `META["avoid"]` 补充）；
- 角色、画风沿用本项目自有的 ppplus107 系列；
- 原视频版权归原发布机构，`course/` 下的内容文档只用于内部教学分析。
