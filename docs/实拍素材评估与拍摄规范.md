# 实拍素材评估与拍摄规范（《高校实验室安全》）

> 目的：评估课程中哪些操作和示例场景加入真实操作视频（实拍）能明显提升学习效果，哪些应保持卡通动画；规定实拍素材的来源、拍摄和接入方式。
> 适用：`project/高校实验室安全/` 全部课程。逐课评估结果见 `curriculum/实拍评估.tsv`（随课程大纲生成）。

## 一、结论（总原则）

**以卡通为主、实拍为辅，实拍只用于"要学生照着做"的规范操作。**

| 适合实拍（真实画面明显更好） | 必须保持动画（实拍不可行或不合适） |
|---|---|
| 需要模仿的手部精细动作和顺序：穿脱个人防护装备、洗手、戴手套和摘手套、生物安全柜内操作、移液器/移液管、滴定、分液漏斗放气、过滤、蒸馏装置搭建 | 事故和危险后果：火灾、爆炸、喷溅入眼、触电、泄漏中毒、针刺、辐射照射、气瓶倒地、低温冻伤 |
| 设备的真实外观和部件位置：洗眼器、紧急喷淋、灭火器（压把、喷嘴、压力表）、通风柜柜门和风速显示、生物安全柜、气瓶阀和减压阀、高压灭菌器、离心机转子与盖 | 看不见的过程和原理：气流、气溶胶扩散、辐射、电流路径、化学反应机理、病原感染途径 |
| 应急器材的实际使用：洗眼器开启和冲洗姿势、紧急喷淋拉杆、泄漏应急处理包、灭火器"提拔握压"（在培训场地用训练灭火器或模拟器）、AED 和心肺复苏（用训练模型） | 错误做法和违规行为（用打叉图标表现，不实拍演示违规操作） |
| 标识和标签的真实样子：国标安全标志、GHS 象形图、化学品安全标签、生物危害标志、电离辐射标志、激光警告标志（拍本校现场或印刷样张） | 法规、制度、管理流程（三级管理、准入、报告流程）——用动画图示更清楚 |
| 本校真实场所的导览：实验室入口信息牌、应急疏散路线、洗眼器/喷淋/灭火器位置、危化品柜、废液暂存点 | 涉及病原体、放射源、剧毒和易制爆化学品的真实操作（安全和安保原因不拍） |

判断一个镜头要不要实拍，按下面四条打分，满 3 条建议实拍：
1. **可模仿性**：学生需要照着做出同样的动作（动作有先后顺序、手法、力度、角度）。
2. **识别性**：学生需要在真实环境中认出这个设备、部件或标识。
3. **可安全拍摄**：拍摄过程不产生真实危险，不用真病原、放射源、剧毒/易制爆品；可用训练器材、清水、模拟物代替。
4. **动画失真风险**：动画模型（MiniMax H3）画不准（如手指精细动作、仪表刻度、阀门旋向、柜门高度标记），可能误导操作。

## 二、素材来源与版权

- **不得使用 441 个原 YouTube 视频的画面**（版权归原作者；且原片常有不规范操作，如不戴护目镜、徒手接线）。原片只作为知识点来源。
- 实拍素材来源只能是：① 本校自行拍摄（推荐）；② 已取得书面授权的教学视频（保留授权文件）；③ 明确允许教育再利用的开放许可素材（记录许可证和出处）。
- 画面中不出现品牌、型号、商标（贴遮挡或选无标识设备），不出现可识别的真实人员面部（除非取得肖像授权），不出现真实事故现场、伤者和新闻画面。

## 三、拍摄规范

- **拍摄安全**：拍摄前由实验室负责人审批拍摄方案；按真实操作要求穿戴个人防护装备；用清水、有色水、训练灭火器、训练模型代替危险物；不开启真实危险源；不演示错误操作。
- **示范规范**：示范者的每一步都必须是正确做法（拍完由学院实验室安全管理员审核）；佩戴护目镜、实验服、合适的手套；长发束起，不戴首饰。
- **技术参数**（与卡通片段一致，便于直接拼接）：横屏 16:9，最终输出 1280×704、24 fps；每个实拍镜头剪成 5 秒（一个分镜一个片段）；手部特写用固定机位或三脚架，光线均匀，背景整洁；不录现场声（旁白统一用配音）。
- **画面内容**：一个镜头只表现一个动作；关键部位特写（阀门、刻度、柜门标线）；必要的文字说明用字幕/图示文字后期加，不在画面里手写。

## 四、制作流程中的接入方式

1. **剧本标记**：在 `src.py` 里，需要实拍的镜头把中文画面写成以 `【实拍】` 开头，后面写清拍摄内容（机位、动作、要点）；英文画面照常写卡通提示词，作为没有实拍素材时的备用动画。
2. **构建**：`build_project.py` 为每节课生成 `实拍清单.md`（镜号、时长、拍摄内容、旁白、要点），供拍摄组使用。
3. **素材放置**：拍好的片段放到 `<制作包>/footage/shot_NNN.mp4`（NNN 为镜号）。
4. **生成**：`generate.py` 默认跳过已有实拍素材的镜头（素材经 `tools/cartoon/live.py` 统一规格后写入 `clips/shot_NNN.mp4`）；没有实拍素材的 `【实拍】` 镜头仍按英文提示词生成卡通片段，保证随时能出完整成片。
5. **配音**：实拍镜头没有 H3 配音，旁白用 TTS（`tts/shot_NNN.wav`）合入。
6. **拼接**：`assemble.py` 照常拼接，字幕、顶部文字、图示文字统一烧录。

## 五、评估结果的使用

- `curriculum/实拍评估.tsv` 逐课列出：是否建议实拍（建议 / 可选 / 不建议）、建议实拍的场景、理由（对应第一节四条标准）、拍摄条件（场地、器材、模拟物）。
- 课程编写时，评估为"建议"的场景在剧本里标 `【实拍】`；每节课实拍镜头一般不超过全片的 30%，保持卡通课程的整体风格。
